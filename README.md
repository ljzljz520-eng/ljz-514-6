# 🏔️ 云顶滑雪场 · 雪道智能推荐

用户选择**所在缆车、滑雪水平、目标雪道、休息站**后，系统综合
**难度、长度、拥挤度、开放状态**推荐一条完整滑行路线（最终返回大本营），
并在地图与路段时间线上**逐段标出风险**。关闭雪道不参与任何计算。

## 运行

纯静态页面（原生 ES Module，零打包）：

```bash
# 任选一种静态服务器
npx serve .          # 或 python3 -m http.server 8000
# 浏览器打开 http://localhost:8000（直接双击 index.html 也可，部分浏览器对 file:// 的 module 有限制）
```

## 算法说明

1. **图模型**：节点为缆车站/山顶/休息站/大本营；边分为
   - `ski` 雪道（下行，要求 `雪道难度 ≤ 用户水平` 才能进入）
   - `lift` 缆车（上行，代价含乘坐时间与排队时间）
2. **关闭雪道**在构建邻接表时直接跳过，下拉框中也禁用，不可能进入推荐结果。
3. **边代价**（越小越优先）：
   - 滑行耗时 = 长度 / 该水平对应速度 + 拥挤附加耗时
   - 难度贴顶 ×3.0、难度接近上限 ×1.6（鼓励选择与水平匹配的雪道）
   - 很挤 +12、较挤 +5；结冰 +6、猫跳 +4、林间 +3
4. **目标雪道强制经过**：把目标雪道作为一段"强制边"插入，仅对其前后做最短路，
   避免最短路径把它绕开。
5. **休息站**：枚举"先休息后滑"与"先滑后休息"两种顺序，取总代价更优者。
6. **逐段风险**（高/中/低三级）：
   - 高：难度贴顶、结冰、非常拥挤
   - 中：难度接近上限、猫跳、林间、地形公园、较挤、长距离体力
   - 低：路况良好
   - 另：难度超出水平直接作为安全问题拦截并说明。

## 边界处理

- 目标雪道关闭 / 难度超出水平 / 图上无连通路线 → 显示明确告警与调整建议，不生成路线。
- 关闭雪道在地图上以灰色虚线 + 🚫 标识，与正常雪道视觉区分。
