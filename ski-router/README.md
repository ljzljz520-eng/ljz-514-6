# 🎿 云岭国际滑雪场 · 智能雪道路线推荐

从零实现的滑雪场雪道推荐系统：**纯前端、零依赖**，直接用浏览器打开即可运行。

## 运行

```bash
# 方式一：直接用浏览器打开 index.html
# 方式二：本地起个服务
cd ski-router && python3 -m http.server 8000
# 访问 http://localhost:8000
```

## 测试

```bash
node test/router.test.js
```

## 功能

| 需求 | 实现 |
| --- | --- |
| 选择所在缆车 | 路线首段固定为乘坐该缆车上山 |
| 选择水平等级 | 新手/初级/中级/高级，超水平雪道**不进图** |
| 选择想去的雪道、休息站 | 作为途经点自动排出最优游览顺序 |
| 按难度/长度/拥挤度/开放状态推荐 | 加权 Dijkstra 最短路，支持 综合/最短/避拥挤/最缓 四种偏好 |
| 关闭雪道不能进入计算 | 构图时直接剔除；已勾选的关闭雪道会被剔除并给出提示 |
| 每段风险标注 | 每段路线给出 低/中/高 风险徽章 + 具体风险因素，地图同步高亮 |

## 算法说明

1. **图模型**：雪道 = 下滑有向边；缆车 = 可上下行的边（下行即“坐缆车下山”）。
   关闭雪道、超过用户水平的雪道在建图阶段剔除，不参与任何计算。
2. **边权**：基础滑行时间（长度 ÷ 按难度/水平修正的速度），再叠加拥挤度与难度惩罚；
   缆车计入乘坐时间与按拥挤度估算的排队时间。
3. **途经点排序**：关键点两两最短路（Dijkstra）后，≤8 个途经点用全排列求最优，
   >8 个用最近邻 + 2-opt 近似。
4. **风险评估**：按“难度 vs 水平、拥挤度、长度、是否黑道”打分，映射为 低/中/高。
