# ⛷️ 雪岭滑雪场 · 智能雪道路线推荐

从零实现的滑雪场路线推荐 Demo：用户选择**所在缆车、水平等级、想去的雪道和休息站**，
系统综合**难度、长度、拥挤度、开放状态**规划完整路线（上山 → 串联全部目标 → 返程回山脚），
并在页面上**清楚标注每一段的风险等级与原因**。

## 运行

无需构建，直接用浏览器打开 `index.html` 即可；或启动本地服务：

```bash
cd ski-planner
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 测试

```bash
node test/planner.test.js   # 9 项断言：关闭设施过滤、不可达告警、风险评级、返程等
```

## 规则设计

| 维度 | 实现 |
|---|---|
| 开放状态 | 关闭的缆车/雪道**不进入图**，绝不参与计算；依赖关闭设施的目标标记为“不可达”并提示原因 |
| 难度 | 难度超过所选水平 1/2/3 级时，路径成本 ×3 / ×8 / ×30，非必要不推荐；必经时标为高风险 |
| 长度 | 折算为滑行时间计入成本（水平越高滑行速度越快） |
| 拥挤度 | 雪道拥挤放大成本（×1 / ×1.2 / ×1.5）；缆车拥挤折算排队时间（+0 / +4 / +10 分钟） |

**分段风险**：每段（缆车乘坐 / 雪道滑行）独立评级 ——
🟢低 / 🟡中（拥挤高、距离长、难度达能力上限、缆车排队）/ 🔴高（难度超出当前水平），
并给出具体原因。地图上的推荐路线段直接按风险色渲染。

## 算法说明

1. **构图**：仅开放的缆车（上行）与雪道（下行）构成有向图；
2. **成本**：`成本 = 时间(长度/速度) × 难度超水平惩罚 × 拥挤惩罚`，缆车另计排队；
3. **串联目标**：从当前位置跑 Dijkstra，贪心选取“到达成本最低”的剩余目标
   （雪道目标 = 到达其起点 + 滑过该雪道），重复直到全部访问；
4. **返程**：自动规划回山脚大厅的最优路径；
5. **风险**：对最终路线的每一段独立评估，整体风险取各段最大值。

## 示例数据说明

- `L5 峡谷缆车`（设备维护）与 `T5 西风道`（雪量不足）为**关闭状态**，用于演示过滤逻辑：
